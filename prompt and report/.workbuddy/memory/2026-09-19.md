## 提取到的关键结构
**VulAgent（arXiv:2509.11523）**：四阶段流水线。视角 = MetaAgent 路由 + 10 个专用分析智能体（基线常开 3 个：Static/Behavior/MemoryLayout）+ Aggregator + TriggerPlanner + AssumptionPruner + FinalValidator。核心是"假设条件 A + 触发路径 P"，上游只求召回禁止剪枝，剪权集中在下游两阶段。报告字段演进：CWE/Location/Description → +trigger_path/assumptions → +assumptions_checked → +Path_validity/cwe_list。

**AAMAS 2026（arXiv:2604.21282，3+1）**：Appendix B 有 4 个智能体的完整 system prompt 原文（Code Analyst / Security Expert / Debug Expert / Adversarial Verifier）。专家统一输出 VULNERABILITY_FOUND/CWE_IDs/SEVERITY/EVIDENCE/CONFIDENCE；验证者输出 DECISION(ACCEPT/CHALLENGE/REJECT)/FINAL_VULNERABILITY/FINAL_CWE_IDS/AGREEMENT_LEVEL/REASONING，且验证者有 override 权。
